# Taquería Doña Alicia - Design Mockup Options

## 🎨 Overview
This repository contains design mockup options for the Taquería Doña Alicia website redesign. Three distinct design directions are presented for review and selection.

## 🔗 Live Preview
**View the comparison page:** [design-showcase.html](design-showcase.html)

## 📋 Design Options Included

### 1. **Cultural Fire** - Heritage & Trust
- Warm, inviting, family-focused design
- Emphasizes authenticity and tradition
- Target: Families and traditionalists

### 2. **Dark Cinematic** - Premium Experience  
- Bold, dramatic, high-end presentation
- Restaurant-quality visual storytelling
- Target: Foodies and experience-seekers

### 3. **Street Art Wild** - Bold & Energetic
- Vibrant, youthful, unapologetic style
- High energy with street food culture vibes
- Target: Young professionals and adventurous eaters

## 🎯 Purpose
Temporary mockup showcase for stakeholder review and design direction selection.
