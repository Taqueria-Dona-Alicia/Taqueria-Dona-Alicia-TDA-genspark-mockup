# Taquería Doña Alicia - Design Mockup Prototypes

## 🎨 Overview
This repository contains **three fully functional design prototypes** for the Taquería Doña Alicia website redesign. Each design direction offers a complete user experience with working navigation, menu browsing, cart management, and checkout flows.

## 📋 Three Design Options

### 1. **Cultural Fire** - Heritage & Trust
**Target Audience:** Families, traditionalists, community-focused customers

**Design Philosophy:** Warm, inviting, and family-focused with emphasis on authenticity and tradition

**Color Palette:** Warm reds (#D84315), oranges (#F57C00), and cream backgrounds

**Key Features:**
- Family story and heritage emphasis
- Social proof and customer testimonials
- Traditional design with modern touches
- Warm, welcoming atmosphere

**[🔗 View Cultural Fire Homepage](cultural-fire/index.html)** | **[🍴 View Menu](cultural-fire/menu.html)** | **[🛒 View Checkout](cultural-fire/checkout.html)**

### 2. **Dark Cinematic** - Premium Experience

**Design Philosophy:** Bold, dramatic, high-end presentation with restaurant-quality visual storytelling

**Key Features:**
- Premium, sophisticated aesthetic

- Cinematic presentation style
- Upscale restaurant positioning

## 🛠️ Features Across All Designs

### Fully Functional Components:
- ✅ **Responsive Navigation** - Works on desktop and mobile
- ✅ **Interactive Menu** - Browse by category, add items to cart
- ✅ **Shopping Cart** - LocalStorage-based cart management
- ✅ **Checkout Flow** - Delivery and pickup options, customer information forms
- ✅ **Customer Authentication UI** - Login/signup modals
- ✅ **Order Confirmation** - Success states and feedback

### Technical Implementation:
- Pure HTML, CSS, and JavaScript (no frameworks needed)
- LocalStorage for cart persistence across pages
- Responsive design for all screen sizes
- Font Awesome icons via CDN
- Google Fonts for typography

## 🎯 Strategic Recommendations

### Choose **Cultural Fire** if you want to:
- Build trust and emotional connection
- Emphasize family heritage and traditional values
- Appeal to families and community relationships
- Create a comforting, authentic experience

### Choose **Dark Cinematic** if you want to:
- Elevate brand perception to premium/upscale
- Attract foodies and experience-seekers
- Compete with higher-end restaurants
- Create a sophisticated, memorable impression

### Choose **Street Art Wild** if you want to:
- Target younger demographics (millennials/Gen Z)
- Build strong social media presence
- Create buzz and viral marketing opportunities
- Position as fun, approachable, and energetic
